# Jokes Desklet for Linux Mint Cinnamon

A lightweight **Cinnamon desklet** that displays random jokes directly on your desktop to brighten your day.

The desklet retrieves jokes from multiple public APIs and allows you to choose the source and type of jokes you want to receive.

---

## Features

- Fetch random jokes from multiple joke APIs  
- Choose between **3 different joke providers**  
- Select the **type of jokes** you want to display  
- Simple and clean desklet design  
- Lightweight and fast  

---

## Supported Joke Sources

This desklet currently supports the following APIs:

- **JokeAPI**  
  https://sv443.net/jokeapi/v2

- **icanhazdadjoke**  
  https://icanhazdadjoke.com

- **Official Joke API**  
  https://official-joke-api.appspot.com

Huge thanks to the creators of these APIs for providing free access.

---

## Installation

Clone the repository: \
```git clone https://github.com/chabymanow/jokes_desklet.git```

Move the desklet folder into your Cinnamon desklets directory: \
```~/.local/share/cinnamon/desklets/```

Restart Cinnamon

Then add the desklet from: \
**System Settings → Desklets**
